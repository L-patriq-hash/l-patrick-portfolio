## Contents

- `index.html` — the complete site (HTML + embedded CSS, no build step required)

## Deploying

This is a static, dependency-free HTML file. Any of the following will work:

**GitHub Pages**
1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under "Build and deployment," set Source to `Deploy from a branch`, branch `main`, folder `/ (root)`.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.

**Any static host** (Netlify, Vercel, Cloudflare Pages, etc.)
- Drag and drop this folder, or connect the repo — no build command needed.

## Notes

- Update `og:url` in `index.html` once you have a live domain, so social previews link correctly.
- Consider adding an `og:image` (headshot or logo) for richer link previews on LinkedIn.
